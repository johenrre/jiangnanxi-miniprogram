# 小程序主题与首页数据配置接口清单

更新日期：2026-08-08

## 1. 数据来源

首页运营配置统一读取：

```text
GET /api/settings/public
```

系统设置仍使用“保存全部设置”，暂未拆分“小程序展示”和“登录与支付”的提交接口。

### 首页主要入口固定槽位

```text
handcraft      开始手作
finished-style 制作同款
```

### 首页快捷入口固定槽位

```text
inspiration-atlas 灵感图鉴
cart              购物车
orders            我的订单
my-designs        我的设计
```

后台只能替换这些槽位的图片，标题和跳转逻辑仍由小程序固定，避免运营配置出无效页面地址。

### 页面风格固定选项

```text
healing-ins        治愈 INS 风（默认）
```

未配置或收到未知值时统一回退到 `healing-ins`。主题变量随小程序代码包发布，后台只选择主题标识，不加载远程 WXSS。

## 3. 未配置时的界面行为

- 页面风格未配置时继续使用现有治愈 INS 主题。

这些运营图片与音乐不再随小程序代码包发布，也没有本地图片兜底：

- 主要入口与快捷入口显示低饱和渐变占位，入口仍可正常点击。
- 制作流程长图、客服悬浮图和音乐按钮在未配置时隐藏。
- Logo / 默认头像未配置时显示轻量 CSS 品牌占位，不会出现裂图。
- 远程图片加载失败时清空对应图片，避免持续重试和真机资源报错。

Logo 和默认头像共用 `siteTitleLogoImage`。登录用户有自定义头像时，仍优先显示用户头像。

## 4. 仍为前端固定内容

- 品牌价值区的 4 个小图标。
- 活动专区首页背景图和活动详情图片均由后台配置；详情页不再渲染奖励阶梯、发布要求等动态文案。
- 首页各入口的标题、描述和路由。
- 搜索、音乐按钮和其他界面图形。

## 5. 缓存与刷新

- 小程序公开配置缓存 30 秒。
- 首页下拉刷新会强制重新请求公开配置。
- 配置缓存版本已升级，旧版缓存不会挡住新增字段。
- 冷启动入口是独立页面 `pages/launch/index`，使用本地开屏图 `assets/launch/resource-preload-v1.jpg`；开屏 UI 不再写在首页里。
- 所有网络图片统一经过 `utils/image-loader.ts`，底层复用 `utils/resource-cache.ts` 的持久缓存；DIY Canvas 与首页预加载共享同一份图片缓存，不重复下载。
- MP3 同样由 `utils/resource-cache.ts` 缓存到小程序用户文件目录。后台上传产生新 URL 后会下载为新资源，缓存按最近使用时间限制在 160 个文件、60 MB 内。
- 开屏最多等待 8 秒。弱网或单个资源失败时使用远程地址继续展示，不把用户困在加载页。
- 分享或扫码直接进入某个业务页时可能跳过开屏页，但 `App.onLaunch` 仍会在后台准备资源，不阻塞目标页面。
- 本地 SVG 图标和活动图已随代码包下载，不参与网络资源缓存。

## 6. 七牛云与真机要求

- 图片和 MP3 使用 HTTPS 地址。
- 管理后台支持直接上传 MP3（最大 10 MB）并自动回填七牛云地址，也保留手动填写 HTTPS 地址的方式。
- 七牛自定义域名同时加入微信小程序图片访问与 `downloadFile` 合法域名。
- JPG 用于照片和长图，PNG 用于透明客服图和二维码。
- 当前 iOS 真机不把 WebP 作为唯一图片格式。
- 流程长图建议 900 × 1896；主要入口建议 1200 × 1024；快捷入口建议 512 × 512。
