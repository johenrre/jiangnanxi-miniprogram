# 结算详情页数据边界

## 当前已接入

- 购物车商品、数量、已选制作/包装/绳线/配送编码：`/api/cart/list`
- 制作、包装、绳色和快递的标题、说明、价格及启用状态：`/api/settings/public.checkoutItemOptionGroups`
- 珠材名称、规格、当前目录单价和图片：`/api/bead/list`
- 非结构化下单说明：`/api/settings/public.purchaseNotice`

## 购物车下单契约

- 小程序提交 `cartItemIds`，不提交 DIY 快照 ID、设计 ID 或购物车数量。
- 后端按当前登录用户的购物车解析商品类型、业务引用和数量，并重新计算价格。
- DIY 购物车条目使用 `diy_design:<designCode>`；商城条目使用 `mall_product:<productId>`。
- 商城“立即购买”不经过购物车，继续提交明确的商品引用。
- 旧版 `items` 下单参数暂时兼容，待已发布小程序完成升级后再移除。

发布时先部署后端，再上传小程序；本次不需要数据库迁移，已有购物车条目可以继续使用。

关键错误码：

- `CART_ITEM_NOT_FOUND`：当前用户的购物车中没有该条目。
- `INVALID_DIY_REFERENCE`：DIY 购物车仍在使用数字设计引用。
- `DIY_SNAPSHOT_NOT_FOUND`：购物车条目存在，但对应 DIY 快照已失效。
- `CHECKOUT_ITEM_UNAVAILABLE`：商城商品不存在或已经下架。

## 仍需后台补充

1. **结构化下单说明**
   - 建议提供 `title + content + sort + enabled`，覆盖天然材质、退换范围、手围确认、制作时长和实物确认。
   - 当前优先展示 `purchaseNotice`；为空时使用页面内置说明作为临时兜底。

2. **购物车珠材快照**
   - 建议购物车返回加入时冻结的珠材 ID、名称、规格、图片、单价和数量。
   - 当前构成清单由 `pattern` 结合最新 `/api/bead/list` 推导，可能与加入购物车时的目录价格不同。
   - 页面明确提示最终金额以购物车和后端计价结果为准。
