# 商城接口与后台商品管理

## 当前已完成

- 小程序商城已经删除 Mock 数据，商品分类、商品列表和商品详情均读取 Node.js 后端。
- 后台管理已增加“商品管理”，支持商品的新增、编辑、上下架和删除。
- 商品管理内提供一级、二级“分类设置”，支持新增、改名、排序和删除空分类。
- 商品售价、划线价、展示销量、排序、分类和图片都由后台人工维护。
- 第一阶段只负责商品展示，不包含库存、SKU、真实销量统计、商城购物车、商城订单或商城支付。

## 小程序公开接口

### `GET /api/mall/categories`

返回后台维护的一级、二级分类及展示顺序。分类暂时没有商品时也会正常返回。

### `GET /api/mall/products`

查询参数：

- `primaryCategoryId`：一级分类，可选。
- `secondaryCategoryId`：二级分类，可选。
- `page`：页码，默认 1。
- `pageSize`：每页数量，默认 20，最大 100。

只返回已上架商品，按后台填写的排序值升序排列。

### `GET /api/mall/products/:id`

返回已上架商品详情；商品不存在或已下架时返回 404。

## 后台管理接口

- `GET /api/admin/mall/products`：商品列表，可按关键词和状态筛选。
- `POST /api/admin/mall/products/create`：新增商品。
- `POST /api/admin/mall/products/update`：编辑商品、上下架。
- `POST /api/admin/mall/products/delete`：删除商品。
- `GET /api/admin/mall/categories`：读取商品分类、排序和商品使用数量。
- `POST /api/admin/mall/categories/save`：保存一级、二级分类的新增、改名、排序和删除。

以上接口需要后台管理员登录。

## 商品字段

- `title`：商品名称。
- `subtitle`：商品副标题。
- `original_price`：划线价，单位为元，最多保留两位小数。
- `discount_price`：展示售价，单位为元，最多保留两位小数。
- `sold_count`：展示销量，由后台人工填写，不统计真实订单。
- `primary_category_id` / `primary_category_name`：一级分类。
- `secondary_category_id` / `secondary_category_name`：二级分类。
- `images`：商品轮播图，第一张同时作为列表封面，最多 10 张。
- `detail_images`：商品详情长图，最多 20 张。
- `status`：`active` 为上架，`inactive` 为下架。
- `sort`：展示顺序，数字越小越靠前。

## 使用流程

1. 打开后台管理的“商品与内容 → 商品管理”。
2. 如需调整分类，点击“分类设置”维护一级、二级分类。
3. 新增商品并上传至少一张商品图片。
4. 将状态设为“上架”并保存。
5. 小程序商城下拉刷新后即可看到该商品。

分类改名会同步更新已有商品。分类仍有商品使用时禁止删除；需要先删除使用该分类的商品，再删除分类。不提供迁移并删除。

商城“加入购物车”和“立即购买”目前仍显示“后续接入”，不创建订单，也不发起支付。
