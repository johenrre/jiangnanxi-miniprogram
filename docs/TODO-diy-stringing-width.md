# DIY 手围计算：占线宽度接口 TODO

## 当前问题

`/backend/api/bead/list.php` 目前只返回 `size`。对圆珠来说它可以作为直径，但对吊坠、挂件和异形配饰来说，`size` 往往是整体外观尺寸，并不是串线位置实际占用的宽度。

新版手围计算会让所有物件参与计算。接口未提供专用尺寸时，前端暂时回退使用 `size`，因此吊坠可能导致建议手围偏大。

## 需要新增的字段

- 字段名：`stringing_width_mm`
- 类型：正数，单位为毫米；建议数据库使用 `DECIMAL(6,2)`，允许为空。
- 含义：物件沿手串绳线方向实际占用的宽度。
- 圆珠：通常等于珠子直径。
- 隔片：填写隔片沿绳方向的厚度。
- 吊坠或挂件：填写顶部连接头、穿绳位或连接珠沿绳方向的宽度，不能填写吊坠整体高度。

接口示例：

```json
{
  "id": 1001,
  "name": "千伞流苏吊坠",
  "size": 28,
  "stringing_width_mm": 3.5,
  "is_pendant": 1
}
```

## 新版建议手围公式

设所有物件的占线宽度总和为 `S`，物件数量为 `N`，平均占线宽度为 `D = S / N`：

- 内圈基准：`B = S - π × D`
- 建议下限：`B - 10mm`
- 建议上限：`B - π × D / N`

最终结果转换成厘米并四舍五入到一位小数。顶部建议手围仅由盘中物件计算，不与用户设置手围联动。

## 校准验收值

| 组合 | 预期建议手围 |
| --- | --- |
| 8mm × 10颗 | 4.5～5.2cm |
| 10mm × 10颗 | 5.9～6.5cm |
| 10mm × 12颗 | 7.9～8.6cm |
| 8mm × 5颗 + 10mm × 5颗 | 5.2～5.9cm |
